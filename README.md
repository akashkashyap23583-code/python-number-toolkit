# 🐍 Python Number Toolkit

A menu-driven Python application that performs various number-related operations.

## 📌 About the Project

Python Number Toolkit is a beginner-friendly Python project designed to perform different mathematical and number-based operations through a simple interactive menu.

The project helps practise Python programming concepts such as loops, conditional statements, arithmetic operators, and number manipulation.

## ✨ Features

This project provides the following 10 operations:

1. Multiplication Table
2. Sum of Numbers
3. Factorial Calculator
4. Fibonacci Series Generator
5. Prime Number Checker
6. Armstrong Number Checker
7. Palindrome Number Checker
8. Reverse a Number
9. Sum of Digits
10. Pattern Printing

It also includes an Exit option to close the program.
